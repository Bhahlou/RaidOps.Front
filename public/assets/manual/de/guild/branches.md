> Nur für Officer.

Ein **Spielzweig** ist eine World-of-Warcraft-Version (Classic Anniversary, MoP Classic, Retail…). Eine Discord-Gilde kann mehrere Spielzweige parallel betreiben — zum Beispiel einen Classic-Anniversary-Roster und einen MoP-Classic-Roster auf demselben Server — jeweils mit eigenem Roster-Zugriff und eigenen Officer-Rollen.

### Einen Spielzweig aktivieren

Die Auswahl **Aktive Spielzweige** listet alle verfügbaren WoW-Versionen auf. Wähle die aus, die deine Gilde aktuell spielt.

Das Deaktivieren eines Spielzweigs löscht nie seinen Roster oder seine Rolleneinstellungen — reaktiviere ihn später, um genau dort weiterzumachen, wo du aufgehört hast.

### Einen aktiven Spielzweig konfigurieren

Jeder aktivierte Spielzweig zeigt seine eigene Einstellungskarte.

**Roster-Zugriff** — zwei Modi:
- **Für alle offen** — jedes Mitglied deines Discords kann dem Roster dieses Spielzweigs beitreten.
- **Discord-Rolle erforderlich** — eine Auswahl **Roster-Rollen** erscheint: Mitglieder mit einer der ausgewählten Rollen können beitreten.

**Officer-Rollen** — unabhängig vom Roster-Zugriff: Mitglieder mit einer der ausgewählten Rollen erhalten Officer-Zugriff auf diesen Spielzweig (bearbeitbarer Roster, Einstellungen, Änderungsverlauf). Discord-Server-Administratoren und der Server-Besitzer behalten unabhängig von dieser Wahl immer vollen Zugriff.

Jede Karte hat ihren eigenen Button **Spielzweig-Einstellungen speichern** — Spielzweige werden unabhängig voneinander gespeichert.

### Zwischen Spielzweigen wechseln

Sobald eine Gilde mehr als einen aktiven Spielzweig hat, erscheinen oben auf den Seiten Roster, Loot und Dashboard Tabs zum Wechseln zwischen ihnen. Eine Gilde mit nur einem aktiven Spielzweig sieht diese Tabs nie — für sie ändert sich nichts.
