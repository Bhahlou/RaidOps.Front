> Officer only.

The **General** tab (in guild settings) configures the guild's timezone, language, which WoW branches are active, and each active branch's Blizzard region.

![Settings page overview](/assets/manual/en/guild/settings-overview.png)

### Timezone

An autocomplete field, automatically pre-filled with your browser's timezone on first load. This timezone is the reference for all guild schedules (raids, calendar).

### Language

The language RaidOps uses to communicate with the guild — the content of every message the Discord bot posts (absences, raid changes, composition announcements, DMs to players, slash-command replies). Until it's ever been saved for this guild, it's just pre-filled from your own browser's language, and a notice makes that clear.

### Saving

Every field on this tab saves automatically as soon as you pick a value — there's no Save button. A confirmation message appears each time.

### Active branches and region

A **branch** is a version of World of Warcraft (Classic Anniversary, MoP Classic, Retail…) — a Discord guild can run several in parallel, e.g. a Classic Anniversary roster and a MoP Classic roster on the same server.

Below the guild's timezone and language, this tab lists every available WoW branch and lets you activate the ones your guild plays. Deactivating a branch never deletes its roster or role settings — you can reactivate it later and pick up exactly where you left off.

Each active branch also gets its own **Region** card (Europe / Americas-Oceania / Korea / Taiwan) — the Blizzard region its realm is on, used to resolve exactly when its raids reset each week. Saved automatically like the rest of this tab.

![Branch activation and region](/assets/manual/en/guild/branches-overview.png)

Once a guild has more than one active branch, tabs appear at the top of the Roster, Loot, and Dashboard pages to switch between them — see the **Roster** guide.

> Roster access and Officer roles are no longer configured here: they're now set per branch, in the **Roster** tab — see the dedicated guide. Each branch's default raid mode lives in the **Raids** tab.
