> Officer only.

**Composition previews** let you simulate what a raid's composition could look like before real characters even exist on the roster — useful right after activating a new branch, before Battle.net import is available for it. A preview belongs to one branch, so switch branches from the tabs at the top of the page if your guild runs more than one.

A preview is a named grid of 1 to 8 groups of 5 — pick whatever count fits the format you're planning for (a 40-man is 8 groups, a 25-man would be 5, and so on). Create as many as you like — a target comp for each format, or several drafts of the same one — and rename, duplicate, or delete them from the list.

### Filling a slot

The class palette (dashed border, right above the grid) lists every playable class with its specs. Drag a spec icon and drop it onto a slot — dropping again on an already-filled slot replaces its placeholder. The small ✕ that appears on hover clears a slot's class/spec without touching its note.

Next to each class name, a number shows how many characters of that class are currently placed in the grid; a badge on each spec icon does the same per spec. The role counter (tank/healer/melee/ranged), on the same header row, tallies the whole grid.

Click a slot to add a free-text **note** — who's expected to play it, a question mark, anything. No restriction on what you type; it's shown in the placeholder's class color once a spec is also set.

The two are independent — a slot can hold just a note, just a spec, both, or neither (an empty slot shows its group.slot coordinate instead of an icon).

### Raid buffs and debuffs

Below the grid, a panel sums up the buffs and debuffs the composition brings, checked against the curated list maintained for the branch's expansion. Three columns: raid buffs, raid debuffs (on the boss), and individual buffs. An effect the composition already covers shows normally; a missing one stays visible but greyed out, with its icon and Wowhead tooltip still active so you can see what it would take to add it.

Two special cases worth knowing:

- **Non-stacking alternatives** (e.g. two spells granting the same armor bonus) share one row with several icons; the row is covered as soon as any one of them is.
- **Blessings and similar capacity-limited effects** appear grouped with an "n/m" counter — each character able to provide one only covers a single one at a time, so N characters cover the first N in the list.

A card also appears under each group in the grid, listing only the icons of the group buffs that group itself provides (nothing shows if it provides none).

If the branch's expansion has no curated buff list yet, this panel doesn't appear at all.

### What this isn't

A preview has no date, no lockout, and no real character — it's a planning tool, not a raid event. See [Raids](/manual/guild/raid-builder) for scheduling and running actual raids with your roster.
