> Officers only.

A **branch** is a World of Warcraft version (Classic Anniversary, MoP Classic, Retail…). A Discord guild can run several branches in parallel — for example a Classic Anniversary roster and a MoP Classic roster on the same server — each with its own roster access and its own Officer roles.

### Activating a branch

The **Active branches** picker lists every available WoW version. Check the ones your guild currently plays.

Deactivating a branch never deletes its roster or its role settings — reactivate it later to pick up exactly where you left off.

### Configuring an active branch

Every activated branch shows its own settings card.

**Roster access** — two modes:
- **Open to everyone** — any member of your Discord can join this branch's roster.
- **Discord role required** — a **Roster roles** picker appears: members holding any of the checked roles can join.

**Officer roles** — independent of roster access: members holding any of the checked roles get Officer access on this branch (editable roster, settings, audit log). Discord server administrators and the server owner always keep full access regardless of this setting.

Each card has its own **Save branch settings** button — branches save independently of each other.

![Branches tab: activation and per-branch settings](/assets/manual/en/guild/branches-overview.png)

### Switching between branches

Once a guild has more than one active branch, tabs appear at the top of the Roster, Loot, and Dashboard pages to switch between them. A guild with a single active branch never sees these tabs — nothing changes for it.
