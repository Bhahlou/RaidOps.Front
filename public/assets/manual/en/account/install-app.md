You can install RaidOps as a real app — straight from your browser, no store, no file to download.

### How to install it

On **Chrome, Edge, Brave, Opera** (and most Chromium-based browsers), an install icon appears in the address bar, to the right of the URL. Click it, then confirm.

On **Safari (iOS/iPadOS)**, use the Share button, then "Add to Home Screen" — there's no automatic icon, you add it manually. Safari on Mac has a similar option ("Add to Dock") from the File menu or the Share button.

**Firefox** doesn't offer this kind of install at the moment.

Once installed, RaidOps opens in its own window — a shortcut on your desktop or home screen, no address bar or tabs:

<img src="/assets/manual/en/account/pwa-installed.png" alt="RaidOps open in its installed window" width="700" />

### Updates arrive on their own

Whether you're using it installed or in a regular tab, RaidOps automatically checks for a new version every time you open the app. If one exists, it downloads it in the background — without ever interrupting what you're doing — then offers to reload the page:

<img src="/assets/manual/en/account/pwa-update-available.png" alt="New version available popup" width="480" />

If you dismiss the popup ("Later"), nothing breaks immediately — but some features may stop working correctly until you reload. The new version stays ready and will be used automatically the next time you load the page.
